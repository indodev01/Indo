# Indo Dev

**Build. Preview. Get Your App.**

Indo Dev is a no-code app builder platform designed to let users create apps without writing code.

## MVP Flow

1. Create account
2. Choose a template
3. Build and customize the app
4. Add data, pages, components, workflows, and Platform Ads
5. Generate and preview the app for free
6. Get a trial APK
7. Trial becomes inactive after 24 hours
8. Activate the app with a paid plan
9. Download/use the activated app

## MVP Modules

- User accounts and projects
- Template library
- Visual app builder
- App definition / versioning
- Preview engine
- Android APK generation
- 24-hour trial and activation
- Subscription and billing
- User app data storage
- Platform Ads abstraction

## Product Principle

The generated apps are white-label: Indo Dev branding should not appear in the user's app unless the user explicitly adds it.
